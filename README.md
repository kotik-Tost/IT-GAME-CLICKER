Консольный кликер с апгрейдами, пассивным доходом, картами, достижениями и античит-системой.

---

## 📥 Скачать

Готовый `.exe` можно скачать в разделе [**Releases**](../../releases).

Просто запусти `NetClicker.exe` — установка не требуется.

---

## 🎮 Управление

| Клавиша | Действие |
|---------|----------|
| `ПРОБЕЛ` | Клик |
| `1` – `6` | Купить апгрейд |
| `P` | Ввести промокод |
| `F` | Колесо Фортуны |
| `M` | Магазин карт |
| `ESC` | Выход с сохранением |

**Промокоды:**
- `NET2026` → +5,000 кликов
- `CLICK` → +10,000 кликов

---

## ✨ Возможности

- 💰 **Активный доход** — клики мышью/пробелом
- ⏱️ **Пассивный доход** — апгрейды работают сами (CPS)
- 🗺️ **4 карты** с множителями до x5
- 🏆 **3 достижения**
- 🎡 **Колесо Фортуны** — раз в 10 минут
- 🎟️ **Промокоды**
- 🛡️ **Античит** — защита от автокликера и зажатия клавиш
- 🌍 **Русский и английский** языки
- 💾 **Автосохранение** каждые 10 секунд
